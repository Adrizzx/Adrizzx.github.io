# Portafolio · Marco Adrian Padilla Triviño

Sitio estático (HTML, CSS y JavaScript, sin dependencias). Para verlo en local basta con abrir `index.html`.

## Publicar en Vercel

1. Crear un repositorio en GitHub llamado `portafolio` y subir el contenido de esta carpeta.
2. Entrar a vercel.com con la cuenta de GitHub, elegir **Add New → Project**, importar `portafolio` y pulsar **Deploy**.
3. No hace falta configurar nada: Vercel detecta que es un sitio estático.

## Editar

- Proyectos: arreglo `PROJECTS` en `script.js`.
- Textos en inglés: objeto `T.en` en `script.js`.
- Imágenes: carpeta `img/`.
- Certificaciones: sección `certs` en `index.html`.
